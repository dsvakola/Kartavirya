# Kartavirya – Reminder Companion

**Version 1.1.0 (Tray & Alert Enhancements)** · Windows desktop app · Tauri v2 + Rust

Press **F12** anywhere, type a task or where you kept something, pick a schedule and press **Enter**. The latest version is on branch `v1.2.1`.

## Features
- Global Quick Capture shortcut (F12) with schedules: Every Hour, Today Evening, Daily, Weekly, Custom.
- Dashboard with search, filters (All, Active, Completed), edit and delete.
- Floating alert window with chime and Windows notification.
- Minimize to system tray (Esc, close button and a tray menu).
- Installer (NSIS) with the app icon and a desktop shortcut, plus a portable exe.
- About and Help windows with the Vidyasagar Academy details.

## Build
Requirements: Rust (stable, MSVC), Node.js and pnpm. Double-click `build.bat`; the installer and portable exe are placed in the `Release` folder.
